# BrainBrick Module 4 — BrainBrick Platform

Module 4 builds the BrainBrick platform page and its supporting content architecture.

## Included

- Platform hero: One brain. Many robots.
- BrainBrick Controller concept
- Robot body / modular body concept
- Sensors and inputs
- Code and logic
- Ecosystem architecture
- Four-stage learning progression
- Platform principles
- Modular platform visual
- Responsive design
- Structured platform data in `src/data/platformData.js`

## Important

The platform content is intentionally positioned as a product/ecosystem concept where final hardware specifications are not yet locked. No unsupported electrical, regulatory, age, price, or performance claims are included.
