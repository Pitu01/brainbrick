# BrainBrick Module 5 — Workshops & Learning Experience

Module 5 adds the BrainBrick hands-on workshop experience.

## Included

- Workshop hero section
- Three workshop formats:
  - Robotics Discovery
  - Robot Builder
  - Robot Creator
- Six-step workshop journey:
  - Understand
  - Build
  - Code
  - Test
  - Improve
  - Share
- Hands-on learning rationale
- BrainBrick learning loop
- Workshop benefits
- Possible workshop settings
- Contact and WhatsApp enquiry CTAs
- Structured workshop content in `src/data/workshopData.js`
- `/workshops` route

## Content discipline

No fixed workshop fee, duration, age limit, certification claim, school approval claim or regulatory claim has been invented. Those can be added after the actual BrainBrick operating model is finalized.
